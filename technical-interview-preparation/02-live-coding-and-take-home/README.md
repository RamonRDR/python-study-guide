## Live coding

A live session evaluates your process under a time constraint. Read the contract aloud, trace a small example, choose a straightforward solution, then code and test. Explain meaningful decisions, not every keystroke. If blocked, describe a smaller verifiable step. At the time limit, state what works, what remains and what you would test next.

## Take-home assignments

A take-home is completed outside the interview. Confirm the expected scope, deadline, submission format, evaluation and permitted tools. Prefer a small working solution with clear assumptions, setup instructions, reproducible tests and known limitations over speculative features. Never include secrets, proprietary code or false claims about execution. If AI use is forbidden, do not use it; if allowed, disclose according to the rules.

For a fictional task that totals nonnegative integer quantities, clarify whether zero is accepted and whether invalid items raise an exception. Document the contract before writing tests. Use an empty input, a single item and an invalid input; then explain the algorithm's time and space cost.

## Independent practice

Choose an existing Phase 11 timed challenge. Attempt it manually under its published time limit. Afterwards, write a short take-home README containing requirements, run instructions, tests you actually executed and two limitations. Compare it with the original contract; do not copy the solution.

**Quick reference:** scope, allowed tools, contract, small solution, evidence, limitations.
