# Assets

This directory is the future home of original visual resources used by Python Study Guide.

## Planned assets

- `logo.svg`: the primary project mark;
- `banner.svg`: a wide visual for the main README and other project pages;
- `repository-preview.png`: the social preview image used when the repository is shared;
- original diagrams and screenshots that provide educational value.

Planned file names may be refined during the visual-identity pull request when the final formats and accessibility requirements are reviewed.

## Asset rules

Visual resources must:

- be original or used under a compatible license;
- include source and license information when created by a third party;
- avoid copying or closely imitating the official identity of Python, OpenAI, or another organization;
- avoid implying affiliation, sponsorship, or endorsement that does not exist;
- remain readable at the sizes in which they will be displayed;
- include meaningful alternative text where the asset is referenced in documentation;
- avoid private, personal, proprietary, or confidential information.

Generated or AI-assisted artwork must receive the same human review applied to documentation and code.

## Current status

The visual identity is still planned and remains one of the pending items in Phase 0. This README currently records the intended scope and quality rules so that the future design work begins with clear constraints.
