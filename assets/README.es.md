## Identidad del banner actual

El banner aprobado utiliza azul marino `#06111F`, cian `#00D0C9` y blanco suave `#F1F5F9` del Learning Hub, con azul `#3776AB` y amarillo `#FFD343` específicos de Python como tokens de diseño. Serpiente geométrica, llaves y libro identifican la guía; el marco hexagonal forma parte del banner aprobado. El PNG es raster, no una matriz vectorial. La paleta, significados y limitaciones siguientes describen solo los recursos originales.

## Significado de la identidad heredada

Serpiente geométrica: Python y aprendizaje continuo; llaves: código e ideas estructuradas; libro abierto: estudio y conocimiento accesible; nodos conectados: relaciones entre conceptos y progreso por práctica. El emblema es original, no reproduce el logotipo oficial Python ni implica afiliación, patrocinio o respaldo de Python Software Foundation u otra organización.

## Orientaciones

Preservar proporciones; no estirar, rotar, recolorear ni redibujar; mantener espacio libre alrededor de emblema/nombre; usar el nuevo banner de presentación en los encabezados de los README; los logotipos y banner originales son históricos; usar texto alternativo significativo; comprobar legibilidad al tamaño final; no ampliar raster más allá del origen; no insertar información privada, personal, propietaria o confidencial.

## Limitación conocida no bloqueante

logo-mark.png tiene 384 × 384 píxeles; repository-preview.svg lo muestra a 440 × 440 píxeles. La ampliación está documentada para mejora futura y no bloquea la fundación actual.
