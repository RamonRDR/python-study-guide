# Recursos da identidade visual

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

Este diretório contém os recursos de identidade visual do Python Study Guide. O banner Learning Hub V1 aprovado é o banner atual dos READMEs (PNG 1280 × 400, arte original 3:1 ajustada sem distorção). Os demais logotipos, prévias e SVGs são recursos legados da identidade original, mantidos por compatibilidade até a aprovação de substitutos. O SVG legado não é a fonte do novo banner.

![Banner Python Study Guide](banner.png)

## Recursos disponíveis

| Arquivo | Finalidade | Uso recomendado |
| --- | --- | --- |
| banner.png | Banner atual com nome e slogan | README principal e páginas |
| logo.png | Logotipo principal com emblema e nome, fundo transparente | Fundos claros e apresentações |
| logo-mark.png | Emblema compacto transparente | Avatares, ícones, diagramas e espaços pequenos |
| repository-preview.png | Imagem social legada | Prévia de compartilhamento GitHub |
| banner.svg | Composição legada editável com emblema raster em Base64 | Ajustes no tamanho original |
| repository-preview.svg | Composição editável com referência local a logo-mark.png | Ajustes no tamanho original |

SVGs não são inteiramente vetoriais: banner.svg incorpora PNG; repository-preview.svg referencia logo-mark.png. Não tratá-los como fontes infinitamente escaláveis. Usar PNGs nas dimensões previstas; não ampliar novos rasters além da resolução de origem.

## Identidade do banner atual

O banner aprovado usa azul-marinho `#06111F`, ciano `#00D0C9` e branco suave `#F1F5F9` do Learning Hub, com azul `#3776AB` e amarelo `#FFD343` específicos de Python como tokens de design. Serpente geométrica, chaves e livro identificam o guia; a moldura hexagonal faz parte do banner aprovado. O PNG é raster, não uma matriz vetorial. A paleta, significados e limitações abaixo descrevem apenas os recursos originais.

## Significado da identidade legada

Serpente geométrica: Python e aprendizado contínuo; chaves: código e ideias estruturadas; livro aberto: estudo e conhecimento acessível; nós conectados: relações entre conceitos e progresso pela prática. O emblema é original, não reproduz logo oficial Python nem implica afiliação, patrocínio ou endosso da Python Software Foundation ou outra organização.

## Orientações

Preservar proporções; não esticar, rotacionar, recolorir ou redesenhar; manter espaço livre ao redor do emblema/nome; preferir logo.png em fundo claro e banner.png em superfícies escuras; usar texto alternativo significativo; conferir legibilidade no tamanho final; não ampliar rasters além da origem; não inserir informações privadas, pessoais, proprietárias ou confidenciais.

## Limitação conhecida não bloqueante

logo-mark.png tem 384 × 384 pixels; repository-preview.svg o exibe em 440 × 440 pixels. A ampliação está documentada para refinamento futuro e não bloqueia a fundação atual.
