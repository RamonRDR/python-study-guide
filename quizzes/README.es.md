# Banco de cuestionarios

[EN](README.md) · [PT-BR](README.pt-BR.md) · [ES](README.es.md)

Empieza por las diez preguntas piloto después de estudiar las lecciones vinculadas. Forman parte del banco previsto de 160 preguntas: siete fáciles y tres medias, 130 XP en total. Cada uno de los cinco tipos objetivos tiene dos preguntas.

Abre los registros JSON en el [índice](quiz-index.json), selecciona `prompt.es` y lee el `code` compartido cuando exista. Responde sin mirar `answer`; después compara tu respuesta y lee `explanation.es` o `hints.es`. Los registros y respuestas son públicos; es práctica, no un examen seguro. Al predecir la salida, incluye el salto de línea final; solo se permite normalización LF cuando se declara. Completar código exige exactamente la palabra clave o nombre de método indicado. No se requiere ni se implementa un runtime en navegador o una cuenta.
