# Quiz bank

[EN](README.md) · [PT-BR](README.pt-BR.md) · [ES](README.es.md)

Start with these ten pilot questions after studying the linked lessons. They are part of the planned 160-question bank: seven easy and three medium, 130 XP in total. The five objective types each have two questions.

Open the JSON records in the [index](quiz-index.json), select `prompt.en` and read the shared `code` when present. Attempt the question without looking at `answer`; then compare your response and read `explanation.en` or `hints.en`. The records and answers are public; this is study practice, not a secure examination. For output prediction enter the final newline; only LF normalization is allowed when declared. Code completion expects exactly the specified keyword or method name. No browser runtime or account is required or implemented.
