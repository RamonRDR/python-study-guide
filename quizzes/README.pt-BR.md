# Banco de quizzes

[EN](README.md) · [PT-BR](README.pt-BR.md) · [ES](README.es.md)

Comece pelas dez questões piloto após estudar as aulas vinculadas. Elas fazem parte do banco planejado de 160 questões: sete fáceis e três médias, 130 XP no total. Cada um dos cinco tipos objetivos tem duas questões.

Abra os registros JSON no [índice](quiz-index.json), selecione `prompt.pt-BR` e leia o `code` compartilhado quando presente. Responda sem olhar `answer`; depois compare a resposta e leia `explanation.pt-BR` ou `hints.pt-BR`. Registros e respostas são públicos; trata-se de prática, não prova segura. Na previsão de saída, inclua a quebra de linha final; somente a normalização LF é permitida quando declarada. Completar código exige exatamente a palavra-chave ou nome de método indicado. Nenhum runtime no navegador ou conta é necessário ou implementado.
