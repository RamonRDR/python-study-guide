## Global definition of done

All new or modified public documentation is available and conceptually aligned in all three languages; tests and links are checked; no known regressions or unresolved relevant findings; no credentials or private data; documentation and task register current; maintainer approves the merge. When validation cannot be run, record what was not run and why rather than marking it passed. Semantic translation review is a human check, not guaranteed by structural validation.

### Sprint 08B · AC-08

08B publishes the first complete curriculum inventory: 14 modules, 107 lessons and eight practical projects, 115 stable chapter IDs and 345 localized content paths. Source ordering and titles must match the three master learning paths exactly (plain display text; remove inline code delimiters only). Module names come from the localized section headings, without phase/status prefixes. Preserve matrix IDs as the reviewed baseline, including the three historical problem-solving exceptions; the matrix is planning evidence, not a consumer input. Use contiguous zero-based module and chapter orders, explicit global previous/next, phase metadata distinct from curriculum order, and canonical localized module indexes. Verify all source paths and tracked chapter coverage. Inventory includes every tracked non-content file under each chapter as a resource, or as an asset for supported image extensions; root assets are tracked images under assets/. Resources are references, not an execution allowlist. Optional dependency paths are declared for the four external-library lessons using the existing shared requirements file; File Organizer is local_only because it exercises platform-specific filesystem behavior. All other chapters are unverified, with no browser compatibility claim. B requires pending association_status and empty typed association lists; C will populate those lists and validate relationships. CI verifies the actual checked-in manifest plus negative regression fixtures; use Git tracked files for authoring inventory, not untracked caches or a consumer's runtime API. No source duplication, new dependencies or site.

### Sprint 08C · AC-08

08C completes the typed association lists using canonical index order. Each quiz/exercise belongs to exactly its existing chapter_id; interview_ids on a chapter are reverse references to questions whose documented prerequisite locale paths identify that chapter, not ownership. mock_ids belong exclusively to the mock-interview lesson; each mock must reference indexed questions and a canonical indexed exercise, with existing order and difficulty preserved. All 253 unique bank records must be represented, with no missing, duplicated, misplaced, invented or dangling associations. Read all four indexes and records with strict JSON (duplicate keys and nonfinite numbers rejected, exact integers preserved); verify declared versions, canonical paths, index coverage and existing record validators, including prerequisite paths/headings and execution metadata. Interview/mock indexes remain preliminary 0.1.0; no new record schema is implied. No bank body or legacy index changes. Retain structural and authoring inventory checks; the complete gate rejects pending or partial relationships. Generate association lists deterministically from the validated banks and compare the checked-in manifest, not generated output alone. No browser compatibility promotion, site, runtime, new dependency or consumer revision claim; D establishes immutable consumption.
