# Registros de entrevistas (preliminar)

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

JSON UTF-8 canónico; `0.1.0` es versión provisional, no esquema final de Sprints 07/08. El [índice](interview-index.json) lista IDs estables y los nueve IDs piloto originales; nombre de archivo es ID más `.json`. Registro tiene topic, level, prompt/expected_answer/explanation/intent/examples localizados, listas localizadas alineadas common_errors y follow_ups, rubric con IDs estables de criterios, puntos enteros positivos y criterio localizado, y mapas de ruta/sección de requisitos previos. Criterio recibe todos sus puntos solo si demostrado; si no cero. Sin evaluación semántica automática. EN predeterminado, PT-BR y ES requeridos. La [lección generada](../technical-interview-preparation/22-technical-interview-question-bank/README.es.md) contiene práctica legible, no segunda fuente de verdad. Ejecuta `python scripts/interview_records.py --write` tras editar registros; ejecuta `python scripts/interview_records.py` y pruebas unitarias del repositorio para validar. Validador comprueba estructura y referencias, no precisión factual ni significado de traducciones; revisa ambos manualmente. Simulaciones y esquemas finales después. Conserva IDs al reordenar; no reutilices.

El índice contiene 57 preguntas técnicas, agrupadas por tema y nivel. Se conservan nueve registros piloto. La tabla de distribución generada se calcula desde registros, no se mantiene aparte. Rutas de requisitos previos pueden referir a lecciones de Fase 12 o lecciones exactas de algoritmos de Fase 11; títulos de sección deben existir en tres idiomas. Preguntas conductuales y simulaciones siguen previstas.
