# Registros de entrevistas (preliminar)

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

JSON UTF-8 canónico; `0.1.0` es versión provisional, no esquema final de Sprints 07/08. El [índice](interview-index.json) lista IDs estables y los nueve IDs piloto originales; nombre de archivo es ID más `.json`. Registro tiene topic, level, prompt/expected_answer/explanation/intent/examples localizados, listas localizadas alineadas common_errors y follow_ups, rubric con IDs estables de criterios, puntos enteros positivos y criterio localizado, y mapas de ruta/sección de requisitos previos. Criterio recibe todos sus puntos solo si demostrado; si no cero. Sin evaluación semántica automática. EN predeterminado, PT-BR y ES requeridos. La [lección generada](../technical-interview-preparation/22-technical-interview-question-bank/README.es.md) contiene práctica legible, no segunda fuente de verdad. Ejecuta `python scripts/interview_records.py --write` tras editar registros; ejecuta `python scripts/interview_records.py` y pruebas unitarias del repositorio para validar. Validador comprueba estructura y referencias, no precisión factual ni significado de traducciones; revisa ambos manualmente. Las simulaciones ya son registros preliminares; los esquemas finales llegarán después. Conserva IDs al reordenar; no reutilices.

El índice contiene 60 preguntas (57 técnicas y tres conductuales/internacionales), agrupadas por tema y nivel. Se conservan nueve registros piloto. La tabla de distribución generada se calcula desde registros, no se mantiene aparte. Rutas de requisitos previos pueden referir a lecciones de Fase 12 o lecciones exactas de algoritmos de Fase 11; títulos de sección deben existir en tres idiomas.

El [índice de simulaciones](mocks/mock-index.json) enumera tres IDs estables. Cada registro contiene nivel, duración, título/instrucciones/autoevaluación/mejora localizados, IDs ordenados de preguntas, ID/ruta de ejercicio, cinco tiempos y cinco dimensiones de rúbrica con puntos completos/parciales fijos e indicadores observables localizados. La dificultad de ejercicio no define seniority. Consulta [lección de simulaciones](../technical-interview-preparation/24-mock-interviews-and-self-assessment/README.es.md). Ejecuta `python -m scripts.interview_mocks --write` para actualizar secciones generadas y `python -m scripts.interview_mocks` para comprobarlas. Toda puntuación sigue siendo manual; sin umbrales de contratación ni evaluación semántica automática. Los esquemas finales se aplazan.
