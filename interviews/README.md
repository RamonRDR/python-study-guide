# Interview records (preliminary)

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

Canonical UTF-8 JSON; `0.1.0` is a provisional version, not the final Sprint 07/08 schema. The [index](interview-index.json) lists stable question IDs and the original nine pilot IDs; the filename is the ID plus `.json`. Each record has topic, level, localized prompt/expected_answer/explanation/intent/examples, aligned localized lists common_errors and follow_ups, rubric with stable criterion IDs, positive integer points and localized criterion, and prerequisite path/section maps. A criterion earns all its points only when demonstrated; otherwise zero. No automated semantic scoring. EN is default, PT-BR and ES required. The generated [study chapter](../technical-interview-preparation/22-technical-interview-question-bank/README.md) contains readable practice, not a second authority. Run `python scripts/interview_records.py --write` after editing records; run `python scripts/interview_records.py` and repository unit tests to validate. The validator checks structure and references, not factual correctness or translation meaning; review both manually. Mocks are now preliminary records; final schemas follow later. Keep IDs stable across reordering; do not reuse them.

The index contains 60 questions (57 technical, three behavioral/international), grouped by topic and level. The nine pilot records are preserved. The generated coverage table is computed from records, not maintained separately. Prerequisite paths may refer to Phase 12 teaching chapters or exact Phase 11 algorithm lessons; headings must exist in all locales.

The [mock index](mocks/mock-index.json) lists three stable mock IDs. Each record contains level, duration, localized title/instructions/self-evaluation/improvement, ordered question IDs, exercise ID/path, five time slots and five rubric dimensions with fixed full/partial points and localized observable indicators. Exercise difficulty is not the definition of interview seniority. See [mock lesson](../technical-interview-preparation/24-mock-interviews-and-self-assessment/README.md). Run `python -m scripts.interview_mocks --write` to refresh generated sections and `python -m scripts.interview_mocks` to check them. All scoring remains manual; no hiring thresholds or automated semantic evaluation. Final schemas are deferred.
