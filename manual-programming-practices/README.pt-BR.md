# Prática manual e engenharia de software

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

Este módulo complementar vem após o currículo central (Fases 1–10) e antes das fases planejadas de resolução de problemas e entrevistas. Não renumera as fases originais. Pré-requisitos: funções, condições, exceções, imports, testes básicos e Primeiros passos. Trabalhe localmente com seu interpretador Python verificado; colaboração remota é opcional. Um exemplo fictício de progresso de leitura conecta depuração manual, especificação, testes e revisão. O estudante escreve e explica o código; manutenção do repositório assistida por IA é um fluxo separado.
