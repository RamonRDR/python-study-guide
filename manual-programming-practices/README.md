# Manual Programming & Engineering Practices

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

This complementary module follows the core curriculum (Phases 1–10) and precedes the planned problem-solving and interview phases. It does not renumber the original phases. Prerequisites: functions, conditions, exceptions, imports, basic tests, and Getting Started. Work locally with your verified Python interpreter; the remote collaboration exercise is optional. One fictional reading-progress example connects manual debugging, specification, tests and review. The student writes and explains the code; AI-assisted repository maintenance is a separate workflow.
