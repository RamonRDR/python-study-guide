Review string iteration and membership, functions and accumulators, boundary testing and complexity before starting. Use the linked prerequisite list in the exercise; no extra Python concepts are required.

Read the contract, predict examples by hand, write pseudocode, implement in a personal file and check outputs. Reveal hints one at a time only if blocked; compare with the solution after an independent attempt. Record errors and explain the complexity. This chapter starts with one easy pilot; additional challenges, including numeric ones, are planned. No browser runner is provided.
