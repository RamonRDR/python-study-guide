# Primeros pasos

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇪🇸 Español](README.es.md)

Este módulo introductorio (orden curricular 00) prepara tu computadora antes de la Fase 1. No requiere experiencia en programación. Es independiente de la Fase 0 histórica (Base del proyecto). Usa una computadora Windows, macOS o Linux, conexión a internet para descargas y permiso para instalar aplicaciones. Si ya tienes Python y editor, verifica tu entorno en vez de reinstalar. Las comprobaciones automatizadas de la guía usan Python 3.13; no necesitas editor de pago, cuenta, suscripción ni asistente de IA. VS Code es recomendable, no obligatorio.

## Ruta de aprendizaje

1. [Instalar Python](01-install-python/README.es.md): Instalar y verificar el intérprete.
2. [Configurar VS Code](02-configure-vscode/README.es.md): Instalar un editor y seleccionar el intérprete.
3. [Ejecutar tu primer programa](03-run-your-first-program/README.es.md): Crear, guardar y ejecutar un archivo Python local.
4. [Entornos virtuales](04-virtual-environments/README.es.md): Crear y comprobar una .venv por proyecto.
5. [Paquetes y gestión de dependencias](05-packages-and-dependencies/README.es.md): Instalar, inspeccionar, registrar y recrear dependencias del proyecto.
6. [Git y fundamentos del control de versiones](06-git-and-version-control/README.es.md): Registrar e inspeccionar cambios; entender la sincronización remota.

## Qué debes demostrar

Puedes identificar tu versión de Python, seleccionar el intérprete deseado, crear un archivo `.py`, ejecutarlo en una terminal y localizar su salida. También puedes crear y seleccionar un entorno virtual local al proyecto, instalar un paquete y recrear el entorno desde un archivo de dependencias. Puedes registrar un commit Git revisado y explicar la diferencia entre un commit local y la sincronización remota. Después continúa con Fundamentos para entender código fuente, ejecución y errores de sintaxis.
